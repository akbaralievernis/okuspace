## 4. Остающиеся проблемы и риски

1. **5 уязвимостей high в dev-зависимостях.** Цепочка `eslint-config-next` → `fast-glob` → `micromatch` → `braces@3.0.3` ([GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm), DoS на глубоко вложенных glob-шаблонах).
   - Исправленной версии `braces` не существует (3.0.3 — последняя). `npm audit fix` предлагает откат на `eslint-config-next@14`, что несовместимо.
   - Уязвимость используется только линтером и только с шаблонами из нашего конфига. В production-сборку она не попадает: `--omit=dev` даёт 0.
   - Риск принят до выхода исправления. В CI блокирует только аудит runtime-зависимостей, полный аудит выводится как отчёт.
2. **e2e шли в Google Chrome 153, а не в Chromium Playwright.** Движок тот же. В CI будет Chromium. Firefox и WebKit не проверялись.
3. **Кыргызские тексты** нужно вычитать носителю языка (этап 4).
4. **Supabase-клиенты не проверены на реальном проекте**: проекта Supabase пока нет. Покрыта только валидация env.
5. **Docker не установлен.** Для тестов RLS на этапе 2 нужен выбор из трёх вариантов ([TESTING_STRATEGY §2](../architecture/TESTING_STRATEGY.md)).
6. **Старый сайт** требует отдельного решения (см. локальный отчёт аудита).
